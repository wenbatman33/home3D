# 藏新幸福 13F · 3D 空間漫遊

依使用者提供 PDF 的左側配置及後續標示重建，包含兩間小孩房、客餐廳、廚房、中島、麻將區、主臥、兩處更衣間、儲藏室、兩間衛浴，以及兩處陽台。

## 開啟

執行 `node server.mjs`，開啟 http://localhost:8080 。無需 npm install 或 build。也可整體上傳 index.html、style.css、app.js、lighting.js、vendor/、assets/ 到靜態主機；透過 HTTP 開啟。

## 操作

- 鳥瞰：拖曳旋轉，滾輪縮放。手機雙指縮放及平移。
- 漫遊：WASD / 方向鍵移動，拖曳轉頭，可鎖定滑鼠；Esc 釋放，Shift 加速。
- 手機：左下搖桿走動，畫面拖曳轉頭，上方導覽列可左右滑动。
- 右側「配色風格」：奶油侘寂、鼠尾草自然、暖灰都會、陶土暖居；選擇儲存在此瀏覽器。
- 日光 / 夜景、原始平面圖、全螢幕及 14 個空間導覽。

## 已修正的配置

- 淨天花高度 3 公尺，視點 1.62 公尺。
- 主臥床頭背後為實牆，更衣間通道在床右側。
- 主衛浴由更衣間進入；上方淋浴區和下方衛浴相連，水箱靠外牆，洗手台沿下方牆面。
- 櫃門把手依櫃高定位，中島椅、書桌椅與麻將椅朝向各自桌面。
- 淡色連續長條木板，櫃體使用可切換的霧面配色；洗手盆與馬桶為實際凹面幾何。

## 光照與效能

目前使用天空環境光、日光與快取陰影；已停用有灰斑的實驗光照貼圖。瀏覽器不載入烘焙圖，不執行路徑追蹤或全螢幕 SSAO。畫面靜止時停止重繪，日夜及視角模式切換時更新陰影。

四組配色即時更新材質。夜景搭配少量暖色燈具。此模式優先確保乾淨表面與漫遊效能，並非完整全局光照模擬。

scripts 中保留實驗性的 Blender 烘焙腳本，尚未採用。產出的 assets/lighting、暫存檔及測試截圖不納入 Git，也不屬於目前瀏覽器渲染流程。

## 建模限制

主體尺寸依圖面比例估算約 7 × 18.7m；層高依使用者要求為 3m。家具款式、欄杆及裝修為設計示意，細部尺寸仍需現場丈量。天空為環境示意，不代表基地的真實周邊景觀。素材來源見 assets/SOURCES.md。
